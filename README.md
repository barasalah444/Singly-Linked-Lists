# Singly Linked List Implementation

A custom implementation of a Singly Linked List data structure in Python. This implementation supports method chaining for cleaner and more readable code.

## Features

- **add_to_front(val)**: Adds a new node to the beginning of the list.
- **add_to_back(val)**: Traverses the list and adds a new node to the end.
- **print_values()**: Iterates through the list and prints all node values.
- **Method Chaining**: All methods return `self`, allowing multiple operations to be chained together in a single line.

## Complexity Analysis

| Operation | Time Complexity |
| :--- | :---: |
| add_to_front | O(1) |
| add_to_back | O(N) |
| print_values | O(N) |
